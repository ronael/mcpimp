# UI Component Resources

Utilise cette capacité quand la demande concerne la génération, l'inspiration,
la comparaison ou l'amélioration de composants UI à partir de références web.

Cette capacité n'est pas une source d'import. Les liens listés ici servent de
repères humains et agentiques : patterns, idées de composants, micro-interactions,
densité visuelle, variantes et conventions d'interface. Ne scrape pas une page
comme vérité produit ; consulte-la seulement si elle peut influencer une décision
concrète de design ou d'implémentation.

## Workflow

1. Lis `references/component-inspiration-links.md`.
2. Sélectionne uniquement les ressources pertinentes pour le composant ou le
   système d'interface à créer.
3. Si une ressource est consultée, transforme l'observation en décision locale :
   structure, état, interaction, accessibilité, responsive ou style.
4. Respecte toujours le design system et les composants existants du projet en
   cours avant d'emprunter un pattern externe.
