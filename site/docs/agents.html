Connect an agent

Documentation · MCP clients

Connect your agent in two minutes.

MCPIMP exposes one local endpoint for Codex, Claude Code, Cursor, and other MCP clients. Prefer streamable HTTP at http://localhost:3901/message.

Run these commands from the MCPIMP repository after installing dependencies.

01Start MCPIMP

Keep the registry running while an agent uses it.

pnpm run dev

02Codex

Add MCPIMP to your Codex user configuration, then restart an open Codex session.

codex mcp add mcpimp --url http://localhost:3901/message

Check the saved server with codex mcp get mcpimp.

03Claude Code

Add MCPIMP at user scope so it is available in every project.

claude mcp add --transport http --scope user mcpimp http://localhost:3901/message

Check the connection with claude mcp get mcpimp.

04Cursor and other clients

Add this entry to the MCP configuration file used by your client.

{
  "mcpServers": {
    "mcpimp": {
      "url": "http://localhost:3901/message"
    }
  }
}
Legacy SSE fallback

If an older client does not support streamable HTTP, use http://localhost:3901/sse instead.

05Verify without an agent

First check the server health, then ask MCP for its tool list.

curl -sS http://localhost:3901/health

curl -sS http://localhost:3901/message \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

Expected tools: list-capabilities, search-capabilities, capability-info, load-capability, and list-upstreams.
