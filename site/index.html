The registry unit

A capability is a directory. Its identity does not change.

A skill (SKILL.md), an upstream MCP (mcp.json), or both. MCPIMP recognizes components, indexes files, and exposes everything under a stable public identifier even when the on disk organization changes.

Find before loading

Ranked search, not a file dump.

Field weights, IDF, and query coverage, plus exact-match bonuses and file-type weighting. A small FR/EN synonym table connects “accessibility” with “accessibilité”. No vector store and no external service.

Sources & provenance

You decide when external content reaches disk.

One JSON file per source in catalog/sources/. Synchronization is read-only by default; the review policy waits for your explicit approval before every update.

› pnpm sources:sync # report, nothing written › pnpm sources:sync --apply # accepts new content
Imported content treated as untrusted data · scripts are never executed
Local overrides live in overrides/ and are never touched by sync
Secrets referenced through env: · nothing is written into mcp.json

Current scope. There are no per-agent permissions, persistent audit logs, or encrypted vaults yet, so these capabilities are not presented as available.

Importe seulement les skills qui te servent.

A repository can contain twenty skills while you only want three. include and exclude filter by slug, while roots limits scanned folders. The rest of the repository never enters your disk.

Anything you adapt locally stays protected: sync replaces upstream/ on every pass, while your files in overrides/ remain intact.

Installation locale

Connect the registry to your agents.

Clone, install, run. Then declare the MCP endpoint in each client using streamable HTTP or SSE, depending on the supported transport.

No account or remote service is required for the registry and its local capabilities.
Terminal
› git clone https://github.com/ronael/mcpimp.git
› cd mcpimp
› pnpm install
› pnpm run dev
MCP configuration — SSE client
{
  "mcpServers": {
    "capabilities": {
      "url": "http://localhost:3901/sse"
    }
  }
}
