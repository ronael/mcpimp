Connecte ton agent en deux minutes.

MCPIMP expose un endpoint local unique pour Codex, Claude Code, Cursor et les autres clients MCP. Utilise en priorité le HTTP streamable sur http://localhost:3901/message.

Lance ces commandes depuis le dépôt MCPIMP après avoir installé les dépendances.

01Lancer MCPIMP

Garde le registry actif pendant que ton agent l'utilise.

pnpm run dev

02Codex

Ajoute MCPIMP à ta configuration utilisateur Codex, puis redémarre une session Codex déjà ouverte.

codex mcp add mcpimp --url http://localhost:3901/message

Contrôle le serveur enregistré avec codex mcp get mcpimp.

03Claude Code

Ajoute MCPIMP au niveau utilisateur pour le rendre disponible dans tous tes projets.

claude mcp add --transport http --scope user mcpimp http://localhost:3901/message

Contrôle la connexion avec claude mcp get mcpimp.

04Cursor et autres clients

Ajoute cette entrée dans le fichier de configuration MCP utilisé par ton client.

{
  "mcpServers": {
    "mcpimp": {
      "url": "http://localhost:3901/message"
    }
  }
}
Repli SSE legacy

Si un ancien client ne prend pas en charge le HTTP streamable, utilise http://localhost:3901/sse.

05Vérifier sans agent

Contrôle d'abord l'état du serveur, puis demande à MCP sa liste de tools.

curl -sS http://localhost:3901/health

curl -sS http://localhost:3901/message \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

Tools attendus : list-capabilities, search-capabilities, capability-info, load-capability et list-upstreams.
